# Command List

### **Everyone**

Sends a direct message to all members in the server.

* **Usage:** `!everyone {message}`
* **Aliases:** `!e`

---

### **Role**

Sends a direct message to all members who have a specific role.

* **Usage:** `!role {role} {message}`
* **Aliases:** `!r`

---

### **Person**

Sends a direct message to a specific user by mention or user ID.

* **Usage:** `!person {person/id} {message}`
* **Aliases:** `!p`
